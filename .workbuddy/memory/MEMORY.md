# 项目长期笔记 · 哈基米生活记录器

## 项目是什么
一款「尿了么 / 拉了么 / 吃了么 / 睡了么 / 活着么」的生活记录 App，带哈基米曼波 IP 人格、积分等级、成就勋章、曼波换装挂勋章、社区与全国/地区榜单。当前交付物是可交互 Web 高保真原型。

## 技术约定
- 纯前端，**无构建、无 npm 依赖**。脚本以经典 `<script>` 按序加载，全局命名空间 `window.HJ`（config / store / audio / ui / app / pageXxx）。
- 加载顺序见 `index.html`：config → store → audio → ui → ctx → 各 page → app。
- 数据持久化在 localStorage（key: `hajimi_life_v1`）。所有数据接口集中在 `js/store.js`，全部为 async，接服务端时只改该文件。
- 音效为 Web Audio 实时合成，无音频素材文件。
- 所有数值、等级名、勋章表、哈基米台词集中在 `js/config.js`，改数值不要动逻辑代码。

## 已确定的产品规则
- 等级 10 级（Lv1 曼波尿泡萌新 → Lv10 哈基米·曼波之神），阈值 0/60/150/280/460/700/1000/1400/1900/2500。
- 解锁：Lv1 尿、Lv2 拉、Lv3 吃、Lv4 睡、Lv5 活着、Lv6 哈基米语音、Lv7 曼波换装、Lv8 哈基米语气、Lv9 社区互动、Lv10 高级安慰。
- 四值（尿/吃/拉/睡）+ 额外值（当天四项全正常 +1，每天只发一次）。
- 睡眠的「正常」状态 key 是 `good`，其它模块是 `normal` —— 判定时必须用 `isNormal()`，不要硬编码。
- 衣服：冬季最多 5 件、夏季最多 2 件；每件内外各 100 个勋章位；闷坏度按超穿件数累计。
- 榜单周/月/年前五发勋章，第一名再发地区/全国勋章。
- 超过 24h 未记录提醒、48h 求安慰、72h 嗝屁风险警告。

## 环境注意事项
- 本机 Git Bash 的 coreutils 不完整（dirname/mkdir 可能找不到），批量文件操作优先用 PowerShell。
- 本机访问 127.0.0.1 的 HTTP 服务会被代理拦截（502），所以本项目刻意不依赖本地 server，直接双击 index.html 即可运行。
